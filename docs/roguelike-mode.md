# 肉鸽闯关模式 · 设计稿（未实现）

> 状态：2026-10-17 设计定稿，尚未实现。用户计划以后再动手。
> 硬约束：**代码保持轻量**（用户明确要求「清亮、别堆各种兜底」）；现有「闯关模式」完全不动，肉鸽作为并存的第二种模式。

## 目标

每过一关，从三张随机增益卡里选一张，永久生效到本局结束，形成「这一局的 Build」。
局内原有的临时道具掉落（11 种）保持不变，两层互不冲突：肉鸽层改参数，临时层给即时效果。

参考同类（2026-10-17 检索）：Brick Survivors: Roguelite（每关三选一，升级分攻/辅两系）、simplegames.io 的 BBTAN 式打砖块（升级分类、硬上限、满级解锁质变卡、可跳过）、Ball x Pit（三选一 + 可感知的 Build 维度）、机核的肉鸽设计方法论（选项必须可量化；用稀有度随进度制造质变点，避免纯数值堆叠）。

## 流程

1. 主菜单增加「肉鸽闯关」入口，与现有模式并存。
2. 每过一关弹出三选一卡牌（暂停游戏状态），选中立即生效并进入下一关。14 关共 13 次选择。
3. 每局一次免费重掷。
4. 死亡即结算：展示本局拿到的全部增益 + 到达关卡；用 localStorage 记最佳记录（沿用现有存档方式）。
5. 不中途存档：一局一次性跑完（与现有闯关模式一致）。

## 增益池（约 18 条）

抽取权重：普通 60% / 稀有 30% / 史诗 10%。每张卡有硬上限，叠满后不再出现在牌堆中。

### 普通（白）

| 增益 | 效果 | 上限 |
|---|---|---|
| 加长挡板 | 挡板宽度 +10% | 3 |
| 慢速球 | 球速 -8%（走现有 itemMul 的 0.62~2.0 夹子） | 3 |
| 好运气 | 道具掉落率 +30% | 2 |
| 急救预备 | 救急掉落阈值 -3 秒（15 → 12 → 9 秒） | 2 |
| 开局补给 | 每关开局随机送 1 个临时道具（复用 applyPower） | 2 |
| 连击狂热 | 连击得分加成（纯爽感） | 无 |

### 稀有（蓝）

| 增益 | 效果 | 上限 |
|---|---|---|
| 多球开局 | 每关开局多一颗球（复用现有「三球齐发」的生成逻辑） | 3（最多 4 球） |
| 精准角度 | 挡板反弹角度收窄一档（更可控，进窄缝更好瞄） | 2 |
| 碎砖 | 击砖 15% 概率直接击碎（无视血量，克制第 8/14 关硬砖） | 2（15% → 25%） |
| 引爆 | 击碎砖 15% 概率炸掉周围一圈（沿用现有爆炸不连锁的规则） | 2 |
| 瞄准线 | 显示球的预测轨迹虚线 | 1 |
| 净化卡池 | 把「挡板缩短」等 3 个负面临时道具踢出掉落池 | 1 |

### 史诗（紫）

| 增益 | 效果 | 上限 |
|---|---|---|
| 免死金牌 | 每关一次免死（球落地不扣命） | 1 |
| 自动炮台 | 挡板每 12 秒自动打一发激光 | 1 |
| 好货必达 | 救急掉落池只出激光/爆炸 | 1 |

### 主题彩蛋（贴第 8/14 关的缝隙玩法）

- **缝隙猎手**：球在一次进缝里停留超过 3 秒，出缝的那一次撞击附带一个小爆炸（奖励「玩缝」流派）。
- **金砖**：每关随机 3 块砖变金色，打碎必掉临时道具。

## 平衡规则

- 13 次选择 ÷ 约 18 条池子 → 每局成型 5~7 条，局与局不同。
- 所有数值乘法叠加，并复用现有 clamp（itemMul 已有 0.62~2.0 上下限）。
- **默认不加难度补偿**：关卡自身递进 + 第 8/14 关缝隙关天然是「构筑检定」。若实测觉得后期被碾，再加一行「每关砖块血量 +5%」的开关。
- 选项必须可量化（写清具体数字），不做「手感更好」这类模糊卡（出自机核方法论）。
- 上限的意义：叠满的卡退出牌堆，后续选择自动转向别的流派，防单一维度碾压。

## 明确不做

- **永久穿透球**：引擎有「穿透球能穿过钢砖 X」的已知 bug，永久穿透会直接废掉第 8/14 关的钢盖设计。要做必须先修 bug。
- 局外成长 / 货币 / 词条融合进化（Ball x Pit 式）：超出「单文件轻量小游戏」的体量，暂不考虑。

## 实现要点（给未来实现者）

- 模式开关放主菜单；选卡界面复用现有浮层按钮（ovBtn）与样式，不引新依赖。
- 增益定义做成一张数据表（id / 档位 / 上限 / 生效方式），buildLevel 时按当前 Build 套参数，不要散着写 if。
- 复用点：多球生成（临时道具「三球齐发」）、applyPower(def)、G.itemMul 的 clamp、救急掉落阈值（G.noHit 的 900 帧判断）、localStorage 存档方式。
- 预计体量 200~250 行，不碰 LEVELS / LEVEL_META 数据。
- 验证：给模拟器 scripts/sim_node.js 加一个「随机选卡跑完 14 关」的回归模式（查无 NaN/报错、14 关可通、极限 Build 不破坏物理）。
