# 打砖块 · Breakout

单文件 HTML5 打砖块小游戏，纯 Canvas 实现，无任何依赖。

在线玩：https://frank-jpeg.github.io/dazhuankuai/

## 玩法

- 14 关，闯关制
- 11 种道具掉落，接到即生效
- 连续 15 秒没打中砖块，会从顶部掉落一个救急道具（激光 / 三球 / 炸弹）
- 后期关卡各有独立机制：摆动砖墙、缝隙关、下压砖墙、爆炸砖
- 支持鼠标拖动 / 触屏 / 键盘（← → 或 A D）移动挡板
- 空格或点击发射球，P 暂停

## 操作

| 动作 | 方式 |
|---|---|
| 移动挡板 | 鼠标拖动 / 手指滑动 / ← → 或 A D |
| 发射球 | 空格 / 点击屏幕 |
| 暂停 | P |
| 切换浅色主题 | 右上角按钮 |
| 跳关（测试用） | 右上角 ⏭ 按钮 |

## 说明

`index.html` 即游戏本体，由主项目 `breakout.html` 同步而来。
